# Fonts

Montserrat is a temporary alternative to Gotham, approved for the landing page.
The variable font supports weights 100–900 and is self-hosted, so the application
makes no runtime request to Google Fonts. Source:
[Google Fonts Montserrat](https://github.com/google/fonts/tree/main/ofl/montserrat).
The original SIL Open Font License is included as `Montserrat-OFL.txt`.

Use `src/styles/fonts.css` for central font loading and `src/styles/theme.css` for
the application font family. Replace the fallback with licensed Gotham webfonts
when supplied. Current semantic weights are medium 500 and bold 700.
