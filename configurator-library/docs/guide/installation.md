# Installation

This guide walks you through installing the **three-configurator** library and setting up your frontend environment.


## 1. Quick Install

Since the library is distributed locally, you can install it into your project using its filesystem path:

```bash
# Install local package folder
npm install ../path/to/three-configurator
```


## Next Steps
Once installed, learn how to initialize the library in the [Getting Started](./getting-started.md) guide.
