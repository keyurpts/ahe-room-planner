# FlatPax Planner

This repository contains the frontend, backend, and configurator library for FlatPax Planner.

## Repository structure

```text
FlatPax-Planner/
├── frontend/              # User-facing application
├── backend/               # Server-side application and APIs
└── configurator-library/  # Configurator logic and reusable components
```
